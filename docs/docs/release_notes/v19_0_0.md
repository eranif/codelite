# CodeLite 19.0.0 Release Notes

This release covers all changes since **18.5.0**. It is a work in progress — this page will be updated as new commits land.

## Improvements

- Reduced the severity of file-read logging in `FileUtils::ReadFileContent`: a failure to open a file is now logged at the DEBUG level instead of ERROR, and a file exceeding the 100 MiB size limit now logs a WARNING instead of an ERROR.

## Bug Fixes

- Fixed a potential null-pointer dereference in the editor's active-tab-changed handler.

## Localization

- Updated Italian translation.
- General translation/PO file refresh.
