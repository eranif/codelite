# CodeLite 19.0.0 Release Notes

This release covers all changes since **18.5.0**. It is a work in progress — this page will be updated as new commits land.

## Improvements

- The **Claude Code** plugin is now called **Agent Host**, and its menu moved to `Plugins` → `Agent Host`. Your existing settings (including the path to the `claude` executable) are kept, and the plugin stays enabled after you upgrade.
- The keyboard shortcut for `Launch Claude Code` changed from `Ctrl-Shift-I` to `Ctrl-Shift-C`.
- The keyboard shortcut for the Diff plugin's `New File Comparison` changed from `Ctrl-Shift-C` to `Ctrl-Alt-C`, to avoid clashing with the new Agent Host shortcut.
- Double-clicking in the built-in terminal now selects a whole URL or command that contains `=` or `?`, instead of stopping at those characters.
- The tab switcher (`Ctrl-Tab`) now uses the same alternate row colours as the rest of the IDE.
- Opening a file that can't be read, or one larger than 100 MiB, is now logged as a debug/warning message instead of an error, which reduces noise in the log.
- Loading a remote workspace is now faster. The SSH connection for the remote language server (LSP) is created in the background, so the UI no longer waits for it. In tests, loading is 3x faster or more.
- **Agent Host** now supports **Kiro CLI**. Start it from `Plugins` → `Agent Host` (`Ctrl-Shift-K`) or from the side bar, next to Claude Code. Each agent type keeps its own page.
- Agent Host now moves the focus to the terminal when you click its tab. The warning about a missing workspace now shows the name of the agent.
- The tab of a read-only editor now shows a lock icon.
- The tooltips of the side bar buttons now show the keyboard shortcut of the action.
- Double-clicking in the built-in terminal now keeps `@` and `&` inside the selected word.
- The `Save` toolbar button and menu item are now enabled only when the editor has unsaved changes.
- The right-click menu of a tab that is not an editor now shows only the close actions (`Close`, `Close All`, `Close Other Tabs`, `Close Tabs To The Right`). The `More Copy Options` submenu is hidden for these tabs.
- The tab bar drawing on macOS now shares the code used on the other platforms, and tab borders use one colour.
- On Linux (GTK), CodeLite no longer shows a dialog and starts `gdb` when it crashes with `SIGSEGV` or `SIGABRT`. It now crashes normally.
- On Linux, a crash (including `SIGABRT`) now prints a stack trace before CodeLite exits.
- Saving a remote file over SFTP is faster: it needs fewer network round trips (5 instead of 7 for an existing file, 4 for a new file). This also makes loading a remote workspace faster on slow connections.
- Creating a remote folder over SFTP now works like `mkdir -p`: missing parent folders are created too.
- **Agent Host** now passes the Chat AI system prompt to the agent. For Claude Code it is sent with `--append-system-prompt-file`. For Kiro CLI it is written to `.kiro/steering/SYSTEM_PROMPT.md` in the workspace. Nothing is written when the system prompt is empty.
- **wxCrafter**: added a `Generate .h files` option. When it is enabled, generated derived-class headers use the `.h` extension instead of `.hpp`.
- On Linux under WSLg, icons are now scaled by `GDK_DPI_SCALE` (between 1 and 2), so they match the size of the other controls.
- **SFTP**: added `Sync Folder with Remote` to the right-click menu of folders in the folder views. Choose the account and the remote folder, select the files, and CodeLite uploads them one by one. When the sync starts, the `SFTP Log` view opens and shows the progress, and you can cancel there. See the [SFTP plugin](../plugins/sftp.md#sync-folder-with-remote) page.
    - The file list has a filter field (not case sensitive, matches any part of the name), `Select All` and `Unselect All` buttons, and the ++space++ key checks or unchecks the selected file.
    - CodeLite remembers the account and the remote folder, and the missing remote folders are created for you.
    - In a File System Workspace with `Enable remote development`, the dialog is filled with the account and the remote folder of the workspace: `<remote workspace folder>/<selected folder, relative to the workspace root>`. If remote development is disabled, or no remote folder is set, the `Remote folder` field is empty.
- **SFTP**: the remote folder and file browser dialog now supports type-ahead search. Type the first letters of a name to jump to the matching entry (typing again within about a second continues the search). `Backspace` still goes to the parent folder.
- **SFTP**: the `Sync Folder with Remote` dialog and the remote browser dialog now use the alternate row colours, and the sync dialog opens at a size that fits its content.
- **Language Server**: the `Language Server` view now has two tabs, `Progress` and `Log`. The `Progress` tab shows the progress that language servers report (for example, indexing). Each task has its own row with the server name, a progress bar and a message, and the row is removed when the task is done. The progress updates are no longer written to the log.
- **File System Workspace**: added a `Sync File On Save` option to the `Remote` page. When it is enabled, every file you save is also uploaded to the remote machine. The option is off by default, so enable it in existing workspaces that use remote development. See the [File System Workspace](../workspaces/file_system.md#remote) page.
- The **Output** pane no longer has the drop-down button and the `Hidden Tabs` menu. The tabs share the available width, and the scroll buttons appear when they do not fit.
- **Agent Host**: after you click a file link in the terminal, the file opens and the editor gets the focus.
- CodeLite now comes with the **Iosevka** font (Iosevka, Iosevka Fixed and Iosevka Term, licensed under the SIL Open Font License). **Iosevka** is the new default editor font, so you do not need to install a font yourself. Your own font choice is not changed.
- When you start CodeLite with a workspace on the command line, CodeLite opens that workspace and does not restore the last session.

## Bug Fixes

- Fixed a possible crash when switching between editor tabs.
- Fixed a crash when opening a `.workspace` file from the command line ([#4080](https://github.com/eranif/codelite/issues/4080)).
- Fixed the **File System Workspace** and **Docker** views losing their view options (for example `Link to Editor` and showing hidden files and folders) after a restart.
- Fixed some tabs of the Output pane being hidden after a restart, with no way to show them again. All the Output pane tabs are now always visible.
- Fixed the selected tab jumping from file to file while CodeLite restores the last session when it loads a workspace.
- Fixed clicking a link in the built-in terminal opening a broken page when the link ended with a period (for example, a URL at the end of a sentence).
- Fixed the Chat AI context-usage counter growing on one-off requests that don't use the conversation history, such as generated code comments.
- Fixed the remote language server (LSP) giving no output after it was restarted in a remote workspace.
- Fixed a read-only request that was refused (because the editor had unsaved changes) still leaving the editor locked.
- Fixed the `Mark Read-Only` menu item keeping an old state when no editor is active.
- Fixed a wrong tab label menu on macOS.
- Fixed the tab icon appearing after the label on Linux (GTK).
- Fixed the tab close button not reacting to clicks. The clickable area did not match the position of the icon.
- Fixed the log going to the terminal (stdout) instead of `codelite.log` when CodeLite starts with a new data directory (`-d`). The log file is now created when it does not exist.
- Fixed the Git Commit dialog starting a new `git` process while another one is still running, and fixed type-ahead search not setting the current item in lists.
- Fixed running a program without the debugger on Windows: CodeLite now starts the correct terminal helper (`glypht`) ([#4150](https://github.com/eranif/codelite/issues/4150)).
- wxCrafter: fixed the `Generate .h files` setting being read only when a project is loaded.

## Build

- `build.sh` now builds wxWidgets `v3.3.3.1` on macOS and Windows, and `v3.3.2` on Linux. wxGTK `v3.3.3` and newer crash the WSLg Weston compositor when copying text with `Ctrl-C`.
- Installed binaries no longer contain the build directory in their `RPATH`. They only look in the plugins directory. This is needed by strict packaging systems such as OBS ([#4079](https://github.com/eranif/codelite/issues/4079)).
- `build.sh` has two new Windows-only targets: `wxcrafter` builds wxCrafter, and `package_wxcrafter` also creates the installer.

## Documentation

- The AI documentation is now in a new section, **AI In CodeLite**, with two pages: [AgentHost Plugin](../AI/agent_host.md) and [Chat AI](../AI/chat_ai.md).
- The old **Claude Code** plugin page was replaced by the **AgentHost Plugin** page. It now covers Claude Code and Kiro CLI, how to enable the plugin, how to set the executable paths, and how the Chat AI system prompt is passed to each agent.
