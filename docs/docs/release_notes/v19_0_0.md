# CodeLite 19.0.0 Release Notes

This release covers all changes since **18.5.0**. It is a work in progress — this page will be updated as new commits land.

## Improvements

- The **Claude Code** plugin is now called **Agent Host**, and its menu moved to `Plugins` → `Agent Host`. Your existing settings (including the path to the `claude` executable) are kept, and the plugin stays enabled after you upgrade.
- The keyboard shortcut for `Launch Claude Code` changed from `Ctrl-Shift-I` to `Ctrl-Shift-C`.
- The keyboard shortcut for the Diff plugin's `New File Comparison` changed from `Ctrl-Shift-C` to `Ctrl-Alt-C`, to avoid clashing with the new Agent Host shortcut.
- Double-clicking in the built-in terminal now selects a whole URL or command that contains `=` or `?`, instead of stopping at those characters.
- The tab switcher (`Ctrl-Tab`) now uses the same alternate row colours as the rest of the IDE.
- Opening a file that can't be read, or one larger than 100 MiB, is now logged as a debug/warning message instead of an error, which reduces noise in the log.
- Loading a remote workspace is now faster. The SSH connection for the remote language server (LSP) is created in the background, so the UI no longer waits for it. In tests, loading is 3x faster or more.
- **Agent Host** now supports **Kiro CLI**. Start it from `Plugins` → `Agent Host` (`Ctrl-Shift-K`) or from the side bar, next to Claude Code. Each agent type keeps its own page.
- Agent Host now moves the focus to the terminal when you click its tab. The warning about a missing workspace now shows the name of the agent.
- The tab of a read-only editor now shows a lock icon.
- The tooltips of the side bar buttons now show the keyboard shortcut of the action.
- Double-clicking in the built-in terminal now keeps `@` and `&` inside the selected word.
- The `Save` toolbar button and menu item are now enabled only when the editor has unsaved changes.
- The right-click menu of a tab that is not an editor now shows only the close actions (`Close`, `Close All`, `Close Other Tabs`, `Close Tabs To The Right`). The `More Copy Options` submenu is hidden for these tabs.
- The tab bar drawing on macOS now shares the code used on the other platforms, and tab borders use one colour.
- On Linux (GTK), CodeLite no longer shows a dialog and starts `gdb` when it crashes with `SIGSEGV` or `SIGABRT`. It now crashes normally.

## Bug Fixes

- Fixed a possible crash when switching between editor tabs.
- Fixed clicking a link in the built-in terminal opening a broken page when the link ended with a period (for example, a URL at the end of a sentence).
- Fixed the Chat AI context-usage counter growing on one-off requests that don't use the conversation history, such as generated code comments.
- Fixed the remote language server (LSP) giving no output after it was restarted in a remote workspace.
- Fixed a read-only request that was refused (because the editor had unsaved changes) still leaving the editor locked.
- Fixed the `Mark Read-Only` menu item keeping an old state when no editor is active.
- Fixed a wrong tab label menu on macOS.
- Fixed the tab icon appearing after the label on Linux (GTK).

## Build

- `build.sh` now builds wxWidgets `v3.3.3.1` on macOS and Windows, and `v3.3.2` on Linux. wxGTK `v3.3.3` and newer crash the WSLg Weston compositor when copying text with `Ctrl-C`.

## Localization

- Updated Italian and Japanese translations.
- Added missing French translations.
- General translation/PO file refresh.
